# Claude Skill: Contributor Workflow Assistance — Actual Budget

**Purpose**: Help developers understand and follow the correct contribution workflow, coding standards, and collaboration practices for the Actual budget monorepo.

---

## 🔹 Contribution Workflow

Follow this structured process when contributing to Actual:

1. **Read Relevant Files**
   - Understand the current implementation before making changes[^4].
   - Review architecture notes and project structure documentation to locate components efficiently[^7].

2. **Set Up Development Environment**
   - Install required tools: Node.js v22+, Yarn 4[^1].
   - Clone the repository and run `yarn` to install dependencies across all packages in the monorepo[^1].
   - Verify setup by running type checking and tests.

3. **Make Focused Changes**
   - Keep changes small and focused on a single feature or bugfix[^4].
   - Avoid large, sweeping changes unless absolutely necessary.

4. **Submit Pull Requests (PRs)**
   - Ensure contributions are complete before submitting[^9].
   - Be prepared to engage in respectful code reviews[^2].

---

## 🔹 Code Style & Conventions

Adhering to consistent coding standards ensures maintainability and readability:

- **Language**: The codebase is written in **TypeScript** with strict type checking enabled[^1].
- **Formatting**: Follow existing patterns in the code; use consistent indentation and naming.
- **Linting**: Run linters locally before pushing code.
- **Documentation**: When writing code comments or documentation, be verbose and assume minimal technical knowledge from the reader[^5].

Refer to the [Code Style Guide](https://actualbudget.org/docs/contributing/code-style/) for full details[^3].

---

## 🔹 Collaboration & Community Expectations

As a contributor, you're part of a collaborative open-source community:

- **PR Reviews**:
  - Participate in reviewing others’ pull requests — it’s expected of all active contributors[^2].
  - Be respectful and constructive; remember PRs come from unpaid volunteers[^2].
  - Ask clarifying questions and push back when needed, but do so politely.

- **Core Contributor Role**:
  - Core contributors help guide the project and share ownership[^2].
  - Share your thoughts openly, stay humble, and contribute to discussions[^2].

- **Funding & Compensation**:
  - Some contributors are compensated via a monthly stipend pool ($1000/month) for administrative and review work[^6].
  - The project is exploring broader compensation for feature work and community participation[^8].
